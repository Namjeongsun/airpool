## 2. 여객자동차운수사업법 (2022년 개정 핵심)

### 2.1 개정의 배경

2022년 개정으로 **택시 합승이 원칙 허용**되었으며, 특히 **IT 플랫폼을 통한 매칭**이 합법화되었습니다. 과거 일반택시의 합승은 승객 안전·요금분쟁 문제로 금지였으나, 개정법은 다음 조건 하에 허용합니다:

### 2.2 합법적 택시 합승 요건 (요약)

| 요건 | 에어풀 대응 |
|---|---|
| **플랫폼을 통한 사전 매칭** (기사 임의 합승 금지) | 에어풀 앱에서 승객 간 사전 매칭 |
| **동성 매칭**(성별 혼합 금지는 폐지됐으나 **승객 동의 필요**) | 여성 전용 매칭 옵션 + 성별 표기 동의 |
| **요금 분담 방식 사전 고지** | 앱 내 분담 금액 사전 표시 |
| **플랫폼 운영자 등록·신고 의무** | 국토부 또는 지방 지자체에 플랫폼 사업자 신고 |
| **사고 발생 시 책임 고지** | 약관에 명시 |

### 2.3 플랫폼 운영사의 역할

에어풀은 **"매칭 중개 플랫폼"** 이며 **운송 사업자가 아닙니다**.
- 직접 운송계약 체결 X
- 운송은 기존 택시사업자(카카오T·우티·일반 중형택시)가 수행
- 승객 간 요금 분담 중개 O (단, 요금 자체는 택시미터기 기준)

## 3. 합법 운영을 위한 요건 체크리스트

| 체크 항목 | 상태 | 비고 |
|---|---|---|
| 플랫폼은 매개 역할만 수행 (운송계약 당사자 아님) | 필수 | 약관 명시 |
| 실제 운송은 면허 있는 택시 사업자가 수행 | 필수 | 카카오T 호출 연동 |
| 합승 매칭은 승객 간 (카풀 유상운송 아님) | 필수 | 승객-승객 구조 |
| 요금 분담은 이용자 자발적 선택 | 필수 | 앱이 강제 X |
| 개인정보 수집 동의 | 필수 | 표준 약관 |
| 위치정보 수집 동의 | 필수 | 위치정보법 별도 동의 |
| 플랫폼 사업자 신고 | 준비중 | 법무 검토 후 진행 |

**카풀과의 구분 (중요)**: 카풀은 자가용 운전자가 승객을 태우는 행위로 **여객운송법상 예외(출퇴근 시간 한정)** 적용. 에어풀은 자가용이 아닌 **정식 택시 합승**이므로 카풀법 규제와 무관합니다.

## 4. 선례 분석

### 4.1 반반택시 (코나투스)

- **2019년 과기부 ICT 규제 샌드박스 1호** 지정으로 심야 합승 합법 허용
- 2022년 법 개정으로 **샌드박스 졸업, 일반 사업자화**
- 현황 (2024~2025 추정): 심야 서울 도심 중심, 누적 앱 설치 수십만 건 단위
- **에어풀 시사점**: ① 법적 경로 명확 ② 동성 매칭·사전 승객 동의 UI 표준화 가능 ③ **새벽/공항 세그먼트는 미개척**

### 4.2 카카오T 합승

- 카카오모빌리티가 자사 택시 호출 내에 합승 옵션 추가
- 대규모 기사 풀 + 즉시성이 강점
- **한계**: 매칭 대상이 무작위 → 공항 근무자 안전·신뢰 니즈 불충분. 새벽 출근용 반복 스케줄 기능 없음.

### 4.3 함의

- 규제 경로는 이미 선배 사업자들이 개척해 둠
- 에어풀은 **재직 인증 + 세그먼트 특화**로 차별화 가능
- 조기 국토부·공항공사와 커뮤니케이션하여 **B2B 제휴 중 법적 리스크 사전 제거** 권장

## 5. 개인정보 보호법 대응

### 5.1 수집 항목 최소화 원칙

| 항목 | 수집 | 저장 형태 | 이용 목적 |
|---|---|---|---|
| 이메일 | O | 평문 | 로그인 |
| 비밀번호 | O | bcrypt 해시 | 인증 |
| 전화번호 | O | SHA-256 해시 + per-user salt | 본인확인·긴급 연락 |
| 이름 | O | AES-256-GCM 암호화 | 결제·법적 의무 |
| 소속 회사 | O | 평문 | 매칭 |
| 사번 | O | **AES-256-GCM 암호화** | 재직 인증 |
| 사원증 이미지 | O | R2 private + 암호화 | 재직 인증 (검토 후 삭제) |
| 위치정보 | O (사용 시) | 세션 메모리 | 매칭 |
| 결제 정보 | X (직접 저장 안 함) | PG사(토스페이먼츠) | 결제 토큰화 |

### 5.2 동의 절차

최초 가입 시 **분리 동의 체크박스** 구성:

- [ ] (필수) 서비스 이용약관
- [ ] (필수) 개인정보 수집·이용 동의
- [ ] (필수) 위치정보 수집·이용 동의
- [ ] (선택) 마케팅 정보 수신 동의
- [ ] (선택) 제3자 제공 동의 (제휴 택시사)

### 5.3 재직 정보 보관 기간

| 데이터 | 보관 기간 | 근거 |
|---|---|---|
| 사원증 이미지 | **승인 후 7일 이내 삭제** | 목적 달성 후 즉시 파기 원칙 |
| 사번(암호화) | 회원 탈퇴 시까지 | 재인증 방지 목적 |
| 재직 인증 승인 기록 | 5년 | 전자상거래법 |
| 결제·정산 기록 | 5년 | 전자상거래법 |
| 불만·분쟁 기록 | 3년 | 전자상거래법 |
| 신고·제재 기록 | 3년 | 이용자 보호 |

### 5.4 이용자 권리 대응

- **열람/정정/삭제 요청**: 앱 내 "개인정보 관리" 메뉴 + `privacy@airpool.kr`
- 요청 후 **10일 이내 처리 완료** (법정 기한)
- 탈퇴 시 즉시 개인정보 삭제 (단, 법정 보관 대상 분리 보관 후 기한 경과 시 파기)

### 5.5 개인정보 국외 이전

- Cloudflare R2: 국외 CDN이나 데이터 센터 **아시아(Seoul/Tokyo) 리전 지정**
- 국외 이전 해당 시 별도 고지·동의 필요

### 6.1 서비스 이용약관 (Terms of Service)

- 재직 인증 요건 및 거짓 인증 시 제재
- 이용자 의무 (성실한 참여, 노쇼 금지, 타인 존중)
- 분쟁 처리 절차
- 서비스 중단·변경 권리
- 분쟁 관할 법원 (서울중앙지방법원 등)

### 6.2 개인정보처리방침 (Privacy Policy)

- 수집 항목·목적·보유기간
- 국외 이전 내역
- 이용자 권리 행사 방법
- DPO(개인정보보호책임자) 연락처
- 쿠키·추적 기술 사용

### 6.3 환불/취소 정책

| 상황 | 처리 |
|---|---|
| 매칭 수수료 납부 후 합승 취소 (24시간 전) | 100% 환불 |
| 합승 당일 취소 (승차 2시간 전) | 50% 환불 |
| 합승 직전 취소 (2시간 이내) | 환불 불가 (노쇼 패널티 부과) |
| 서비스 오류로 매칭 실패 | 100% 환불 + 바우처 |

### 6.4 노쇼·분쟁 처리 기준

- **노쇼 1회**: 경고 + 크레딧 차감
- **노쇼 2회 (30일 내)**: 14일 이용 정지
- **노쇼 3회**: 영구 정지
- **성희롱·폭언 신고**: 즉시 매칭 풀 제외, 조사 후 영구 정지
- **요금 미납**: 자동 청구 3회 실패 시 매칭 차단

## 7. 예상 법적 리스크 및 대응

### 7.1 승객 간 분쟁

**리스크**: 합승 중 갈등(에어컨, 경로, 요금분담 비율), 개인물품 분실
**대응**:
- 합승 룰(대표자 지정, 분담 비율 사전 합의) 앱 내 안내
- 앱 내 신고 채널 + 24시간 CS 대응
- 분쟁조정위원회(한국소비자원) 연결 안내

### 7.2 택시 기사와의 분쟁

**리스크**: 합승 거부, 경로 이탈, 요금 초과
**대응**:
- 카카오T/우티 등 기존 호출 플랫폼 API 사용 → 해당 플랫폼 약관 내 분쟁 처리
- 에어풀은 기사와 직접 계약관계 없음을 약관에 명시
- 기사 관련 클레임은 원 플랫폼으로 이관

### 7.3 사고 발생 시 책임 주체

**구조**:
- 운송 사고 → **택시 사업자의 공제/보험 적용** (여객운수법상 의무)
- 앱 매칭 오류로 인한 손해 → 에어풀이 제한된 범위 내 책임 (약관상 면책 한도 명시)

**약관 면책 문구 예시**:
> "본 서비스는 이용자 간의 택시 합승 매칭을 중개하는 플랫폼이며, 실제 운송 중 발생하는 사고에 대한 책임은 해당 운송사업자 및 보험약관에 따릅니다. 단, 회사는 고의 또는 중대한 과실로 이용자에게 손해를 끼친 경우 「민법」 등 관련 법령에 따라 책임을 집니다."

### 7.4 재직 인증 정보 유출

**리스크**: 사원증 이미지·회사명·사번 유출 → 해당 항공사로부터 손해배상 청구 가능성
**대응**:
- 사원증 원본 이미지 승인 후 7일 내 삭제
- 모든 인증 데이터 암호화
- 연 1회 정보보호 인증(ISMS-P) 획득 목표 (MAU 10만 전후)
- 사이버보험 가입 (연간 보험료 수백만원 규모 추정)

### 7.5 성희롱·안전사고

**리스크**: 새벽 시간 합승 중 성범죄·사고 발생 시 플랫폼 책임론
**대응**:
- 여성 전용 매칭 옵션 기본 제공
- 실시간 위치 공유 기능 (가족·지인 대상)
- 앱 내 SOS 버튼 (112 연결)
- 신고 이력 통합 관리, 위험 사용자 사전 차단
- 공항 도착 후 자동 안전 확인 푸시
