# 에어풀(AirPool) 사업 기획서

> **프로젝트명**: 에어풀 (AirPool) — 공항 근무자 전용 택시 합승 매칭 플랫폼
> **문서 버전**: v1.0
> **작성일**: 2026-04
> **대상 독자**: 시드/프리A 투자자, 파트너사(항공사·공항공사), 내부 팀

---

## 1. 개요 (Executive Summary)

**에어풀(AirPool)** 은 인천국제공항·김포국제공항으로 통근하는 승무원·조종사·지상직·공항 상주 근무자 전용 **택시 합승 매칭 앱**입니다.

공항 근무자는 새벽 4~5시의 극단적 출근 시간과 대중교통 공백으로 인해 **월 150~250만원 수준의 교통비 부담**을 홀로 떠안고 있습니다. 에어풀은 **재직 인증을 통과한 동일 출근 시간대·유사 출발지 근무자들을 자동으로 매칭**하여 택시비를 2~4인이 분담하도록 돕습니다.

- **시장**: 인천공항 상주 종사자 약 8만 명, 김포공항 약 1.5만 명, 국적 항공사 승무원·조종사 약 1.8만 명 (추정, 2024년 공항공사·국토부 공시 기반)
- **수익 모델**: 매칭 수수료(합승 1건당 1인 500~1,000원) + 월 구독(9,900원/월) + B2B 복지 연계
- **차별점**: 재직 인증 필수 → 일반 합승 서비스 대비 높은 안전성·신뢰도
- **법적 근거**: 2022년 개정 「여객자동차운수사업법」에 따른 **플랫폼 중개 택시 합승 합법화**
- **3년 목표**: MAU 10만, ARR 30억원, 제2·제주·부산공항 확장

**투자 포인트**: ① 명확한 고통(monthly pain) 정량화 가능 ② 재직 인증으로 기존 플레이어가 복제 어려움 ③ 항공사·공항공사 B2B 레버리지 존재.

## 2. 문제 정의

### 2.1 공항 근무자의 출퇴근 실태

| 직군 | 주요 출근 시간 | 특이사항 |
|---|---|---|
| 국제선 승무원 | 04:00 ~ 05:30 브리핑 | 쇼업 지각 시 비행 제외, 징계 대상 |
| 조종사 | 04:30 ~ 05:00 브리핑 | 생체 리듬 관리 의무 |
| 지상직(발권·탑승) | 04:00 ~ 05:00 OP | 교대제 |
| 공항 상주 상업시설 | 05:00 ~ 06:00 오픈 | 새벽 인력 공백 |

**대중교통은 이 시간대를 커버하지 못합니다.** 공항철도 첫차는 인천공항T1 기준 평일 05:20 출발(서울역 방면)이며, 역방향(서울→공항)은 첫차가 05:23입니다. 서울 서남부·강남권 거주자는 첫차를 타도 브리핑 시간을 맞출 수 없습니다.

### 2.2 인천공항 접근성 비용 (추정치, 2025년 실거래 택시앱 기준)

| 출발지 | 편도 택시비 (심야·새벽) |
|---|---|
| 강남역 | 80,000 ~ 95,000원 |
| 잠실 | 75,000 ~ 90,000원 |
| 마포·공덕 | 65,000 ~ 80,000원 |
| 분당(정자) | 95,000 ~ 120,000원 |
| 일산(정발산) | 60,000 ~ 75,000원 |

※ 새벽 할증(20~40%) 포함 추정치. 실제는 기사·경로·톨게이트에 따라 차이.

### 2.3 기존 대안의 한계

- **공항버스**: 노선·시간 제약. 강남 6009번 첫차 04:35, 대부분 노선은 05:00 이후 → 브리핑 04:00 대응 불가.
- **공항철도 + KTX**: 첫차 커버 안 됨. 또한 캐리어·유니폼·제복 착용 상태에서 환승 부담.
- **자차**: 공항 장기주차 월 약 **15~25만원** + 기름값. 1주 이상 비행 스케줄 시 방치 부담.
- **개인 택시 고정 예약**: 월 150~250만원 (편도 7~9만원 × 월 20~25회 왕복 절반 기준).

### 2.4 수치화된 고통

> **승무원 A (강남 거주) 월 교통비 추정**
> 편도 85,000원 × 출근 22일 = **1,870,000원/월**
> → 합승 2인 시 935,000원, 3인 시 623,000원, 4인 시 467,500원
> **3인 매칭 성공 시 월 약 124만원 절약**

이 금액은 국적 승무원 **초봉(250~300만원대) 대비 월급의 35~50%에 해당**하는 규모입니다.

## 4. 솔루션

### 4.1 핵심 사용자 플로우

```
[가입] → [재직 인증] → [매칭 조건 입력] → [자동 매칭] → [채팅 확정]
        ↓
    → [택시 호출 (카카오T/우티)] → [합승] → [앱 내 정산] → [상호 평점]
```

### 4.2 4-Key 매칭 엔진

1. **공항 (인천T1 / T2 / 김포)**
2. **지역 (출발지 3km 반경 클러스터링)**
3. **시간 (브리핑 역산 ±30분 윈도우)**
4. **날짜 (스케줄 표 기반 D+0 ~ D+30)**

### 4.3 신뢰 시스템

- **재직 인증 필수**: 사원증·재직증명서·e-메일(@koreanair.com 등) 3중 인증
- **실명제**: 닉네임은 허용하되 매칭 상대방에게는 "소속(항공사/협력사) + 직군" 노출
- **평점·리뷰**: 합승 완료 시 상호 평점. 평점 3.0 미만 시 매칭 풀에서 제외
- **블랙리스트**: 노쇼·결제 미납·성희롱 신고 누적 시 영구 차단

### 4.4 비용 분담 UX

- 합승 확정 → 대표자가 택시 호출 → 도착 후 앱 내 **자동 N분할 요청** → 카카오페이/토스 간편송금
- 공항 도착 시 **자동 정산 알림** 푸시

## 6. 비즈니스 모델

### 6.1 수익 모델 4종

**Option A — 매칭 수수료 (주력)**

- 합승 성사 시 1인당 500~1,000원
- 2인 매칭: 1,000원 × 2 = 2,000원 / 건
- 3인 매칭: 800원 × 3 = 2,400원 / 건
- 4인 매칭: 600원 × 4 = 2,400원 / 건
- 사용자 입장: 편도 2~3만원 절감 대비 수수료 500~1,000원은 **절감액의 2~5%** 수준

**Option B — 월 구독 (고빈도 유저용)**

| 플랜 | 가격 | 혜택 | 타겟 |
|---|---|---|---|
| 에어풀 Basic | 무료 | 월 3회 매칭 | 일반 |
| 에어풀 Pro | 9,900원/월 | 무제한 매칭 + 우선 배정 | 승무원·지상직 |
| 에어풀 Captain | 19,900원/월 | Pro + 차량 지정 + 여성 전용 | 프리미엄 |

**Option C — 프리미엄 기능 (단건 결제)**

- 여성 전용 매칭: 건당 +1,000원
- 같은 항공사 전용 매칭: 건당 +500원
- 조종사 전용 라운지: 월 3,000원

**Option D — B2B 복지 연계**

- 항공사 사내 복지 포인트 연동 (통근비 지원금 자동 차감)
- 공항공사 상주 협력사 단체 계약 (연간 인당 30,000원)
- 예상 계약처: 대형 FSC 2곳, LCC 3곳, 지상조업 3곳

### 6.2 3년차 ARR 시나리오

**가정**:
- Y3 MAU 100,000명
- 월 평균 합승 6회 = 월 600,000건
- 평균 수수료 1,800원/건 (3인 기준)
- 구독 전환율 15% = 15,000명 × 9,900원
- B2B 계약 30,000명 × 연 30,000원

| 수익원 | 연 매출 |
|---|---|
| 매칭 수수료 | 600,000 × 1,800 × 12 = **약 129.6억원** |
| 구독 | 15,000 × 9,900 × 12 = **약 17.8억원** |
| 프리미엄 기능 | 추정 **약 8억원** |
| B2B | 30,000 × 30,000 = **약 9억원** |
| **합계 ARR** | **약 164억원** |

> 보수 시나리오(MAU 5만)는 ARR 약 45억원, 낙관 시나리오(MAU 15만 + 지방공항)는 약 250억원.

## 7. 경쟁 환경

### 7.1 직접 경쟁자

**반반택시 (코나투스)**
- 심야 택시 합승 서비스. 2019년 과기부 ICT 규제 샌드박스 1호.
- 강점: 선구자 포지션, 법적 리스크 조기 해소
- 한계: **일반 시민 대상**이라 새벽 공항 니즈에 최적화 안 됨, 공항 외곽까지 기사 유입 저조, 재직 인증 없음

**카카오T 합승**
- 카카오모빌리티의 합승 옵션. 확장성·기사 풀 최대.
- 한계: **합승 대상 무작위 → 공항 근무자 입장 신뢰·심리적 저항 큼**. 새벽 출근용 스케줄 매칭 기능 없음. 여성 근무자 안전 우려.

### 7.2 간접 경쟁자

- **공항버스** (6009, 6003 등): 저가지만 시간대·노선 제약
- **공항리무진 예약제 셔틀**: 일부 항공사 승무원 대상 운영, 이용 제약 많음
- **자차 + 공항 주차**: 월 15~25만원 주차비, 비행 기간 방치 부담

### 7.3 에어풀을 선택해야 할 이유 (Positioning Statement)

> "공항 출근길, 동료끼리 타는 택시."
> 신뢰 가능한 동료와 합승 → 절반 이하 가격 + 브리핑 정각 도착 보장.

## 8. 마케팅 전략

### 8.1 Phase 1 (M0~M3): 시드 유저 100~500명 확보

**채널 우선순위**

1. **네이버 카페**: "승무원 준비반", "항공사 사우회", "지상직 모여라" — 합법적 후기·체험단
2. **블라인드**: 인천공항·대한항공·아시아나·제주항공 등 인증 게시판
3. **사내 노조 게시판**: 제휴 제안 (노조 복지 할인 제공)
4. **인스타그램·유튜브 승무원 인플루언서**: 마이크로 인플루언서 10~20명 협업, 무료 크레딧 지급

**런칭 캠페인**

- 첫 합승 100% 무료
- 친구 초대 시 양쪽 3,000원 크레딧
- 매칭 3회 시 5,000원 추가 크레딧
- CAC 목표: 15,000원 이하 (LTV 180,000원 가정 시 LTV/CAC 12:1)

### 8.2 Phase 2 (M3~M11): 본격 성장

- **인천공항 셔틀 승강장·흡연실 오프라인 스티커** (공항공사 광고 협의)
- **항공사 사내 복지 연계 제휴** (B2B 씨딩)
- 공항 근무자 익명 커뮤니티 **광고 배너**
- **리뷰 이벤트**: 월간 최다 합승 유저 상품 (면세점 상품권)

### 8.3 Phase 3 (Y2+): 확장

- 지방 공항 진출 (부산·제주·청주) 시 해당 항공사 정비사·승무원 타겟
- **외국 항공사 한국 주재 승무원** (Qatar, Emirates 인천 base) 다국어 지원
